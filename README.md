# Hi, I'm Robert 👋

CS major (software engineering minor) at Tusculum University and a college sprinter. I build security tools in Python, from scratch, with tests and CI.

## Projects

- **[raw-packet-analyzer](https://github.com/23rob/raw-packet-analyzer)**: a packet sniffer and threat detector on Linux raw sockets, standard library only. It decodes Ethernet/IPv4/TCP/UDP/ICMP byte by byte, runs a threaded pipeline with drop accounting, and detects SYN floods and port scans mapped to MITRE ATT&CK.
- **[network-port-scanner](https://github.com/23rob/network-port-scanner)**: an async multi-host TCP scanner with TLS banner grabbing and CIDR support. It has 93 tests at 96% coverage and CI, and the README documents the benchmarks and a real bug I found along the way.
- **[password-strength-checker](https://github.com/23rob/password-strength-checker)**: entropy scoring, pattern detection, and policy presets, with JSON output and CI-friendly exit codes.

All three are indexed in [cybersecurity-projects](https://github.com/23rob/cybersecurity-projects).
